GIT CHEAT SHEET (فارسی) — برای تلگرام
تمام دستورها داخل یک کدبلاک (برای کپی یکجا):

```
==============================
۱) شروع و کلون
==============================
git init
یک پروژه گیت خالی در پوشه فعلی می‌سازد.

git clone https://github.com/USER/REPO.git
کپی کامل ریپو را از گیت‌هاب می‌آورد.

git clone https://github.com/USER/REPO.git SUBFOLDER
مثل بالا ولی در یک زیرپوشه مشخص.

==============================
۲) وضعیت و تغییرات
==============================
git status
وضعیت: کدام فایل‌ها تغییر کرده/جدید/آماده کامیت هستند.

git diff
فقط تغییرات فایل‌های unstaged.

git diff --staged
تغییرات staged (آماده کامیت).

git log --oneline -10
۱۰ کامیت آخر به‌صورت خلاصه.

==============================
۳) کامیت
==============================
git add .
همه تغییرات را stage می‌کند.

git add FILE
فقط یک فایل را stage می‌کند.

git commit -m "پیام"
ثبت کامیت با پیام.

git commit -am "پیام"
add + commit یکجا (فایل‌های track شده).

git restore FILE
برگرداندن تغییرات unstaged یک فایل.

git reset HEAD~1
حذف آخرین کامیت (فایل‌ها می‌مانند).

==============================
۴) برنچ
==============================
git branch -M main
تغییر نام برنچ فعلی به main.

git checkout -b NEWBRANCH
ساخت برنچ جدید و ورود به آن.

git branch
لیست برنچ‌ها.

==============================
۵) ریموت و پوش
==============================
git remote -v
دیدن آدرس ریموت‌ها.

git remote add origin URL
اضافه کردن ریموت origin.

git push -u origin main
اولین پوش + ست کردن (بعد فقط git push).

git push origin main
پوش تغییرات به گیت‌هاب.

git pull origin main
آوردن آخرین تغییرات گیت‌هاب (قبل از کار بزن).

==============================
۶) Git Bash مسیرها
==============================
cd /c/Users/NAME/Desktop/FOLDER
ورود به پوشه در Git Bash.

code .
باز کردن پوشه در VS Code.

==============================
۷) ساخت توکن (PAT)
==============================
GitHub → Settings → Developer settings → Personal access tokens → Generate
فقط تیک repo → Generate → توکن را کپی کن.
وقتی گیت Password خواست، توکن را paste کن (رمز نیست!).
توکن یک‌بار نشان داده می‌شود؛ سیو کن.

==============================
۸) نکته ویندوز
==============================
git config core.autocrlf true
بی‌صدا کردن هشدار LF/CRLF (بی‌خطر است).

==============================
۹) خطرناک‌ها (با احتیاط)
==============================
git reset --hard HEAD~1
حذف کامل آخرین کامیت و تغییراتش.

git push --force
اعمال reset روی گیت‌هاب (فقط وقتی تنها هستی).
```

💡 یادت نره:
قبل از هر کار: git pull origin main
پوش بعدی این پروژه:
git add .
git commit -m "..."
git push origin main
